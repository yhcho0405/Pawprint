# Pawprint 모험 모드 구현 명세

이 문서는 Pawprint 0.10.0 기본 UI를 유지하는 RPG 통합 개발 브랜치의 **현재 턴제
모험 구현**을 설명합니다. 공개 Pawprint 0.10.0 DMG에는 포함되지 않은 개발판 사양입니다.
기획 아이디어나 향후 목표가 아니라, 지금 실행되는 코드의 수치와 규칙을 기준으로
합니다.

> 핵심 결론: 고양이 희귀도 등급은 HP·공격·방어에 소폭 적용됩니다. **모험 레벨은 이제
> 레벨 2·4·6에서 경로를 해금하지만 전투 능력치를 올리지는 않습니다.** 결속과 경로
> 도장은 여전히 전투 효과가 없는 저장 카운터입니다.

## 한눈에 보기

| 항목 | 현재 구현 |
|---|---|
| 파티 | 지난날의 서로 다른 고양이 정확히 3마리 |
| 탐험 구조 | 일반전 → 유물 → 일반전 → 유물 → 보스전 |
| 행동 | 매 턴 고양이 1마리를 골라 기본 공격 또는 역할 스킬 사용 |
| 경로 | 여섯 기운을 모두 쓰는 개별 설계 경로 6개, 3개는 레벨로 해금 |
| 전투 자원 | 파티 공용 HP와 공용 마나 |
| 영구 진행도 | 모험 XP(레벨은 XP에서 계산), 완주 횟수, 경로 도장, 고양이별 결속 |
| 일시 보상 | 해당 탐험에서만 쓰는 유물 최대 2개 |
| 자동 진행 | 없음. 버튼으로 명령을 내릴 때만 한 턴 진행 |
| 레벨 능력치 보정 | 없음 |
| 레벨 해금 | 새벽 정원 레벨 2, 한낮 정거장 레벨 4, 깊은밤 연구실 레벨 6 |
| 결속·도장 효과 | 누적 저장만 구현, 전투 효과와 소비처는 없음 |
| 진행 중 탐험 복원 | 없음. 앱을 다시 실행하면 활성 탐험은 복원되지 않음 |

기본 진행 순서는 다음과 같습니다.

```text
도감에서 모험 열기
  → 지난날의 고양이 3마리 선택
  → 경로 선택
  → 일반전 1
  → 유물 1개 선택
  → 일반전 2
  → 유물 1개 선택
  → 보스전
  → 점수·랭크·보상 정산
```

## 서로 다른 세 종류의 등급

| 이름 | 범위 | 무엇으로 정해지나 | 현재 효과 |
|---|---|---|---|
| 고양이 희귀도 등급 | S~D | 기존 Pawpet 희귀도 | HP·공격·방어 소폭 보정 |
| 탐험 결과 랭크 | S~D | 완주 점수 또는 실패 여부 | 경로 배율을 적용하기 전 기본 XP 결정 |
| 모험 레벨 | 1부터 상한 없음 | 누적 모험 XP | 레벨 2·4·6 경로 해금, 능력치 보정 없음 |

고양이의 S등급과 탐험 결과의 S랭크는 이름만 같을 뿐 별개입니다. 결과 랭크, XP, 모험
레벨, 결속, 경로 도장은 고양이 희귀도 등급을 다시 쓰거나 전투 능력치를 변경하지
않습니다. 모험 레벨은 선택 가능한 경로만 바꿉니다.

## 모험에 참가할 고양이

### 후보와 파티 규칙

- 오늘보다 이전 날짜에 완성된 갤러리 고양이만 후보가 됩니다. 오늘 고양이는 제외됩니다.
- 기본 후보 목록과 자동 추천은 최신 날짜부터 처리합니다. HUD 표시는 S→A→B→C→D
  등급순이며 같은 등급 안에서는 최신 날짜부터 정렬합니다.
- 파티에는 날짜 ID가 서로 다른 고양이 정확히 3마리가 필요합니다.
- 역할 중복은 허용됩니다. 수호·공격·지원을 반드시 한 마리씩 넣을 필요는 없습니다.
- 자동 추천은 가능한 경우 역할별 1마리를 먼저 고른 뒤 남은 자리를 최신 후보로 채웁니다.
- 세 역할을 모두 넣어도 별도의 수치형 조합 보너스는 없습니다. 다만 모든 적 예고에
  대응할 수 있다는 구성상의 이점이 있습니다.

### Pawpet 외형을 RPG 특성으로 바꾸는 규칙

모험 엔진에는 기존 고양이의 네 가지 특성만 직접 전달됩니다. 다른 외형·활동 특성은
직접 전달되지 않지만, 기존 Pawpet 희귀도 산정에 포함되는 특성은 고양이 등급을 통해
HP·공격·방어에 간접 영향을 줄 수 있습니다.

| Pawpet 특성 | RPG 특성 |
|---|---|
| 무늬(`pattern`) | 역할 |
| 오라(`aura`) | 기운 |
| 표정(`expression`) | 패시브 |
| 희귀도 등급(`rarityGrade`) | 고양이 등급 |

#### 무늬 → 역할

| 무늬 코드 | 역할 |
|---|---|
| `plain`, `tuxedo`, `bicolor` | 수호(`guardian`) |
| `tabby`, `spotted`, `calico` | 공격(`striker`) |
| `colorpoint`, `star` | 지원(`support`) |

#### 표정 → 패시브

| 표정 코드 | 패시브 |
|---|---|
| `content`, `zen` | 침착함(`steady`) |
| `sleepy`, `tired`, `dizzy` | 회복력(`resilient`) |
| `determined`, `focused`, `sparkle` | 집중(`focused`) |
| `chaotic`, `mischief` | 기회 포착(`opportunist`) |
| `surprised`, `wide` | 기민함(`alert`) |

#### 활동 시간 → 오라 → 기운

오라는 기존 Pawpet 규칙에 따라 정해진 뒤, 동일한 시간대 코드의 모험 기운과 1:1로
연결됩니다. 두 UI의 한국어 표시 이름은 일부 다릅니다. 기준 시간은
`골든 아워 → 가장 바빴던 분의 시각 → 첫 활동 시각 → 정오` 순서로 선택합니다.

| 기준 시각 | Pawpet 오라 | 모험 기운 |
|---:|---|---|
| 00:00~04:59 | 심야빛(`deepNight`) | 심야(`deepNight`) |
| 05:00~07:59 | 새벽빛(`dawn`) | 새벽빛(`dawn`) |
| 08:00~11:59 | 아침빛(`morning`) | 아침(`morning`) |
| 12:00~16:59 | 낮빛(`afternoon`) | 오후(`afternoon`) |
| 17:00~20:59 | 저녁빛(`evening`) | 저녁(`evening`) |
| 21:00~23:59 | 밤빛(`night`) | 밤(`night`) |

### 희귀도와 고양이 등급

모험에서 쓰는 등급은 하루 활동 점수의 등급을 직접 복사한 값이 아니라, 기존
Pawpet의 **희귀도 등급**입니다.

```text
희귀도 원점수 =
  0.70 × 아이템 희귀도 점수
  + 0.30 × (Pawpet 활동 노력도 × 100)

희귀도 정수 = 희귀도 원점수를 가장 가까운 정수로 반올림
```

Pawpet 활동 노력도는 `0...1`, 아이템 희귀도 점수와 원점수는 `0...100` 범위입니다.
원점수는 소수 둘째 자리로 반올림해 계산하고, 모험 등급은 다시 가장 가까운 정수로
반올림한 희귀도로 정합니다. 이 값은 기존 일별 기록에서 다시 계산되며 별도 RPG 저장
필드가 아닙니다.

| 희귀도 정수 | 고양이 등급 |
|---:|---:|
| 85 이상 | S |
| 70~84 | A |
| 50~69 | B |
| 30~49 | C |
| 0~29 | D |

모험 엔진은 이 최종 등급만 받아 사용하며 희귀도나 노력도를 다시 계산하지 않습니다.

## 파티 능력치

### 계산 표기

| 기호 | 뜻 |
|---|---|
| `A` | 등급 보정까지 적용된 행동 고양이의 공격력 |
| `G` | 등급과 침착함 보정까지 적용된 행동 고양이의 방어력 |
| `P` | 현재 적의 전투력 |
| `HPmax` | 세 고양이 최대 HP의 합 |
| `w` | 해당 턴의 결정론적 난수 보정 |

양수의 나눗셈은 정수 나눗셈이므로 소수점 이하는 버립니다.

### 역할별 기본 능력치

| 역할 | 기본 HP | 기본 공격 | 기본 방어 | 기본 치유력 | 역할 스킬 |
|---|---:|---:|---:|---:|---|
| 수호 | 112 | 22 | 10 | 0 | 앞발 방패 |
| 공격 | 100 | 30 | 2 | 0 | 번개 덮치기 |
| 지원 | 106 | 20 | 4 | 10 | 포근한 그루밍 |

역할 스킬의 세부 피해·방어·회복 보너스는 아래 전투 공식에서 다룹니다.

### 고양이 등급 보정

| 고양이 등급 | 내부 보너스 `B` | HP 증가 | 공격 증가 | 방어 증가 | 치유력 증가 |
|---|---:|---:|---:|---:|---:|
| D | 0 | 0 | 0 | 0 | 0 |
| C | 2 | 2 | 1 | 0 | 0 |
| B | 4 | 4 | 2 | 1 | 0 |
| A | 6 | 6 | 3 | 1 | 0 |
| S | 8 | 8 | 4 | 2 | 0 |

```text
최대 HP = 역할 기본 HP + B
공격력 = 역할 기본 공격 + B / 2
방어력 = 역할 기본 방어 + B / 4 + (침착함이면 3)
치유력 = (지원이면 10, 아니면 0) + (집중이면 3)
```

패시브를 제외한 역할·등급별 실제 수치는 다음과 같습니다. 각 칸은
`HP / 공격 / 방어` 순서입니다.

| 등급 | 수호 | 공격 | 지원 |
|---|---:|---:|---:|
| D | 112 / 22 / 10 | 100 / 30 / 2 | 106 / 20 / 4 |
| C | 114 / 23 / 10 | 102 / 31 / 2 | 108 / 21 / 4 |
| B | 116 / 24 / 11 | 104 / 32 / 3 | 110 / 22 / 5 |
| A | 118 / 25 / 11 | 106 / 33 / 3 | 112 / 23 / 5 |
| S | 120 / 26 / 12 | 108 / 34 / 4 | 114 / 24 / 6 |

희귀도 등급은 치유력을 올리지 않습니다. 가능한 파티 최대 HP 범위는 같은 역할의
중복을 허용할 때 `300...360`입니다.

### 파티 공용 HP와 행동 고양이

- 세 고양이의 최대 HP를 합쳐 하나의 파티 공용 HP로 사용합니다.
- 개별 HP나 개별 전투불능 상태는 없습니다.
- 매 턴 선택한 고양이 한 마리의 공격·방어·기운·패시브만 행동 계산에 사용됩니다.
- 행동하지 않은 두 고양이는 그 턴에는 공용 최대 HP에만 기여합니다.
- 표시 방어력 `G`가 그대로 피해에서 빠지는 것은 아닙니다. 기본 피해 경감에는
  `G / 2`가 사용됩니다.

등급의 방어 보정은 먼저 `G`에 적용된 뒤 다시 `G / 2` 정수 나눗셈을 거칩니다. 따라서
방어 `+1`이 모든 고양이와 턴에서 즉시 피해 경감 `+1`로 나타나는 것은 아닙니다.

## 턴과 행동

### 기본 공격

```text
최초 피해 = max(1, 2A / 3 + w), w = -2...2
```

- 공용 마나를 1 회복합니다. 최대 마나를 넘지 않습니다.
- 역할 스킬의 역할별 피해 보너스는 받지 않습니다.
- 지원 고양이도 기본 공격으로는 회복하지 않습니다.
- 역할이 적 예고와 맞으면 약한 대응 보너스와 대응 성공 판정을 받을 수 있습니다.

### 역할 스킬

```text
최초 피해 = A + w + 역할 피해 보너스, w = -2...2
```

| 역할 | 역할 피해 보너스 | 추가 효과 |
|---|---:|---|
| 수호 | +4 | 피해 경감 잠재치에 +8 |
| 공격 | +8 | 추가 효과 없음 |
| 지원 | +0 | 파티 회복 |

역할 스킬은 공용 마나 1을 소비합니다. 마나가 0이면 행동 자체가 거절되어 턴과 난수
상태가 변하지 않습니다.

### 플레이어 피해 계산 순서

1. 기본 공격 또는 역할 스킬의 최초 피해를 계산합니다.
2. 기운 일치, 패시브, 적 예고 대응, 유물 보너스를 더합니다.
3. 적이 방어 태세인데 공격 역할로 대응하지 못했다면 적 방어
   `max(6, P / 5)`를 뺍니다.
4. 실제 피해를 `min(적 현재 HP, max(1, 시도 피해 - 적 방어))`로 제한합니다.

유효한 행동은 적에게 최소 1의 피해를 줍니다. 실제 기록값은 적의 남은 HP를 넘지
않으므로, `피해 +4` 효과가 처치 직전에는 4보다 작아 보일 수 있습니다.

## 기운과 패시브

### 기운 일치

행동 고양이의 기운이 적의 기운과 **완전히 같을 때만** 피해 보너스를 받습니다.

| 행동 | 일치 피해 보너스 |
|---|---:|
| 기본 공격 | `max(2, A / 10)` |
| 역할 스킬 | `max(3, A / 6)` |

기운 사이에 가위바위보식 강약이나 불리 상성은 없습니다. 일치하면 보너스를 받고,
불일치하면 중립으로 처리됩니다. 행동하지 않은 고양이의 기운도 그 턴에 영향을 주지
않습니다.

### 패시브 효과

| 패시브 | 조건 | 현재 턴제 효과 |
|---|---|---|
| 침착함 | 항상 | 방어력 `+3`, 적 반격 시 추가 피해 경감 `+4` |
| 회복력 | 행동 시작 시 파티 HP가 최대 HP의 50% 이하 | 추가 피해 경감 `+8` |
| 집중 | 역할 스킬 사용 | 치유력 `+3` 및 역할 스킬 회복 `+4` |
| 기회 포착 | 행동마다 25% 확률 | 피해 `+7` |
| 기민함 | 각 전투의 첫 턴 | 피해 `+5` |

침착함의 방어력 `+3`은 `G / 2`에도 반영되고, 그 뒤 추가 피해 경감 `+4`도 별도로
더해집니다. 회복력의 50% 조건은 그 턴의 회복보다 먼저 판정합니다. 기민함은 탐험 전체의
첫 턴이 아니라 세 전투 각각의 첫 턴에 다시 발동할 수 있습니다.

## 적 예고와 대응

적 예고는 공개 정보입니다. 대응 역할의 고양이를 선택하면 기본 공격도 대응 성공으로
기록되지만, 역할 스킬의 효과가 더 큽니다.

| 적 예고 | 대응 역할 | 미대응 효과 | 역할 스킬 대응 | 기본 공격 대응 |
|---|---|---|---|---|
| 강한 내리치기 | 수호 | 높은 적 공격 | 피해 `+3`, 피해 경감 `+max(12, P / 3)` | 피해 `+1`, 앞 경감 보너스의 절반 |
| 방어 태세 | 공격 | 적 방어 `max(6, P / 5)` | 적 방어 제거, 피해 `+10` | 적 방어 제거, 피해 `+5` |
| 흡수 안개 | 지원 | 추가 피해 `max(8, P / 7)` | 추가 피해 제거, 피해 `+3`, 피해 경감 `+max(8, P / 5)`, 회복 `+8` | 추가 피해 제거, 피해 `+1`, 앞 경감 보너스의 절반, 회복 없음 |

적 공격의 독립 난수 `w`도 `-2...2`입니다.

| 적 예고 | 적 공격 시도값 |
|---|---:|
| 강한 내리치기 | `3P / 4 + w` |
| 방어 태세 | `2P / 5 + w` |
| 흡수 안개 미대응 | `P / 2 + max(8, P / 7) + w` |
| 흡수 안개 대응 | `P / 2 + w` |

적 공격은 피해 경감 전에 최소 1로 제한됩니다.

## 방어와 받는 피해

```text
피해 경감 잠재치 =
  G / 2
  + 수호 행동 보너스
  + 예고 대응 보너스
  + 패시브 보너스
  + 유물 보너스
```

| 항목 | 피해 경감 보너스 |
|---|---:|
| 수호 기본 공격 | +3 |
| 수호 역할 스킬 | +8 |
| 침착함 | +4, 방어력 `G +3` 효과와 별도 |
| HP 50% 이하의 회복력 | +8 |
| 푹신 망토 | +4 |
| 강한 내리치기·흡수 안개 대응 | 위 대응표의 수치 |

```text
실제 피해 경감 = min(적 공격, max(0, 피해 경감 잠재치))
받은 피해 = min(회복 후 파티 HP, max(0, 적 공격 - 실제 피해 경감))
```

플레이어 행동으로 적을 먼저 처치하면 적은 반격하지 않습니다. 이때 받은 피해와 기록상
피해 경감은 모두 0입니다.

## 회복

회복은 역할 스킬에서만 발생하며, 플레이어의 피해를 처리한 뒤 적의 반격보다 먼저
적용됩니다.

```text
회복 가능량 =
  치유력
  + 지원 역할 스킬 보너스
  + 흡수 안개 대응 보너스
  + 집중 역할 스킬 보너스
  + 회복 허브 보너스

실제 회복 = min(회복 가능량, HPmax - 현재 파티 HP)
```

| 항목 | 회복 보너스 |
|---|---:|
| 지원 역할 스킬 | +12 |
| 지원으로 흡수 안개 대응 | +8 |
| 집중 상태의 역할 스킬 | +4 |
| 회복 허브를 가진 지원 역할 스킬 | +8 |

대표 회복 가능량은 다음과 같습니다.

| 행동 고양이 | 일반 역할 스킬 | 흡수 안개 대응 | 회복 허브 포함: 일반 / 대응 |
|---|---:|---:|---:|
| 비집중 수호·공격 | 0 | 해당 없음 | 해당 없음 |
| 집중 수호·공격 | 7 | 해당 없음 | 해당 없음 |
| 비집중 지원 | 22 | 30 | 30 / 38 |
| 집중 지원 | 29 | 37 | 37 / 45 |

집중 패시브가 있으면 비지원 역할도 스킬 사용 시 회복 가능량이 7이 됩니다. 단, 실제로
잃은 HP가 없으면 회복량은 0입니다. 패시브 이름인 `회복력(resilient)`은 HP가 낮을 때
방어를 높이며, 여기서 말하는 치유력과는 다른 개념입니다.

## 난수와 재현성

- 플레이어 피해 흔들림은 행동마다 `-2...2`입니다.
- 적 공격 흔들림은 행동마다 `-2...2`입니다.
- 기회 포착은 `0...3` 중 0일 때 발동하므로 정확히 25%입니다.
- 각 적은 순서가 정해진 예고 패턴을 가집니다. 시드가 시작 위치를 고른 뒤 해당 패턴을
  반복합니다. 같은 예고를 여러 번 넣어 별도의 숨은 확률 판정 없이 더 자주 나오게 할
  수 있습니다.
- 같은 전체 전투 상태에서 같은 고양이와 행동을 선택하면 같은 결과가 나옵니다.
  시드·스테이지·라운드가 같으면 플레이어 피해와 적 공격의 흔들림, 기회 포착 판정,
  예고 순서가 같습니다.
- 거절된 행동, 창 숨김, UI 재생성, 대기 시간은 난수나 전투 상태를 바꾸지 않습니다.
- 실시간 제한, 자동 턴, 방치·오프라인 진행은 없습니다.

## 경로와 스테이지

모든 경로는 일반전 2회와 보스전 1회로 고정됩니다. 일반전은 각각 3턴, 보스전은 5턴까지
진행할 수 있습니다. 실제 경로는 세 적을 따로 설계하므로 앞선 스테이지를 보스 전투력의
비율로 자동 생성하지 않습니다. 적 전투력 `P`는 `1...1000`, 명시한 최대 HP는
`1...2000`으로 제한됩니다. 호환용 초기화는 여전히 HP 기본값을 `2P`로 만들지만 아래
여섯 경로는 모두 HP를 직접 지정합니다.

| 경로 | 기운 | 최소 레벨 | 난이도 | XP 배율 |
|---|---|---:|---|---:|
| 햇살 숲길 | 아침 | 1 | 쉬움 | 100% |
| 신호 지붕길 | 저녁 | 1 | 보통 | 100% |
| 심야 기록실 | 밤 | 1 | 보통 | 100% |
| 새벽 정원 | 새벽빛 | 2 | 보통 | 115% |
| 한낮 정거장 | 오후 | 4 | 어려움 | 130% |
| 깊은밤 연구실 | 심야 | 6 | 전문가 | 130% |

난이도는 경로를 설명하는 정보이며 별도의 숨은 스케일링 공식을 적용하지 않습니다. 잠긴
경로도 선택 목록에서 미리 볼 수 있지만 필요한 모험 레벨에 도달하기 전에는 탐험을 시작할
수 없습니다. 도장과 완주 횟수는 경로 해금에 쓰이지 않습니다.

반복하되 시드에 따라 첫 예고의 위치가 회전합니다.

### 전투 승패와 스테이지 전환

- 적 HP가 0이 되면 즉시 승리합니다.
- 파티 HP가 0이 되면 패배합니다.
- 마지막 허용 턴이 끝났을 때 적이 살아 있으면 패배합니다.
- 마지막 턴에 적을 처치했다면 턴 제한 패배보다 승리가 우선합니다.
- 일반전에서 패배하면 탐험 전체가 즉시 끝납니다.
- 유물 효과를 적용하기 전의 파티 HP와 마나는 다음 스테이지로 이어집니다. 따뜻한 차는
  HP를, 마나 방울은 현재·최대 마나를 바꾼 뒤 다음 전투를 시작합니다.
- 스테이지 사이 자동 완전 회복은 없습니다.

## 마나

| 항목 | 규칙 |
|---|---|
| 시작 마나 | 2 |
| 기본 최대 마나 | 3 |
| 기본 공격 | 마나 `+1`, 최대치까지만 |
| 역할 스킬 | 마나 `-1` |
| 마나 0에서 역할 스킬 | 행동 거절 |
| 스테이지 전환 | 현재 마나 유지 |
| 마나 방울 획득 후 최대치 | 4 |

남은 마나는 결과 상태에 포함되지만 점수나 XP에 반영되지 않습니다.

## 유물

첫 번째와 두 번째 일반전에서 이길 때마다 아직 보유하지 않은 유물 3개를 제시합니다.
하나를 선택해야 다음 전투가 시작됩니다.

- 전체 유물은 6종입니다.
- 같은 유물은 중복 획득할 수 없습니다.
- 보스전에 도달하면 유물 2개를 보유합니다.
- 제시 목록은 탐험 시드와 스테이지에 의해 결정됩니다.
- 모든 유물은 현재 탐험에서만 유효하고 영구 저장되지 않습니다.

| 유물 | 정확한 효과 |
|---|---|
| 날카로운 발톱 | 모든 기본 공격·역할 스킬의 시도 피해 `+4` |
| 푹신 망토 | 적 반격에 대한 피해 경감 `+4` |
| 마나 방울 | 최대 마나 `+1`, 선택 즉시 현재 마나 `+1` |
| 따뜻한 차 | `max(1, HPmax / 5)`만큼 즉시 회복, 최대 HP 초과 불가 |
| 메아리 부적 | 적 예고에 대응하면 행동의 기본 마나 변화 뒤 마나 `+1` |
| 회복 허브 | 지원 역할 스킬의 회복 가능량 `+8` |

메아리 부적으로 역할 스킬 대응에 성공하면 소비한 마나 1을 되돌려받을 수 있습니다.
기본 공격 대응으로 이미 최대 마나에 도달했다면 최대치를 넘겨 추가 회복하지 않습니다.

## 완주 점수와 결과 랭크

패배 또는 철수의 점수는 항상 0입니다. 보스를 처치했을 때만 다음 공식을 사용합니다.

```text
체력 점수 = 남은 파티 HP × 25 / 파티 최대 HP
대응 점수 = 대응 성공 횟수 × 20 / 전체 행동 횟수
효율 점수 = max(0, 10 - 3 × max(0, 전체 행동 횟수 - 8))

최종 점수 = min(100, 40 + 체력 점수 + 대응 점수 + 효율 점수)
```

각 나눗셈의 소수점 이하는 버립니다.

| 점수 요소 | 최대점 |
|---|---:|
| 완주 기본 | 40 |
| 남은 HP 비율 | 25 |
| 적 예고 대응 비율 | 20 |
| 턴 효율 | 10 |
| 현재 구현상 최대 | 95 |

| 총 행동 횟수 | 효율 점수 |
|---:|---:|
| 8 이하 | 10 |
| 9 | 7 |
| 10 | 4 |
| 11 | 1 |

| 결과 랭크 | 조건 |
|---|---:|
| S | 완주 점수 90 이상 |
| A | 완주 점수 85~89 |
| B | 완주 점수 75~84 |
| C | 완주 점수 74 이하 |
| D | 패배 또는 철수 |

현재 세 스테이지의 최대 행동 횟수는 11이므로 완주 점수 범위는 실질적으로
`41...95`입니다. 현재 판정에서는 완주 D랭크가 발생하지 않습니다. 엔진에 완주 D랭크의
40 XP 분기가 남아 있지만 현재 랭크 판정으로는 도달할 수 없습니다.

점수 공식은 최종 남은 마나나 유물 개수를 직접 읽지 않습니다. 다만 탐험 중의 마나
운용과 선택한 유물 효과는 전투 성과를 바꾸므로 점수에 간접적으로 영향을 줄 수
있습니다. 다음 항목도 전투 성과를 통해 점수에 간접적으로 영향을 줄 수 있습니다.

- 선택한 경로에 직접 설계된 적·HP·예고 패턴과 고정 난이도
- 고양이 희귀도 등급과 역할 구성 자체

모험 레벨은 시작할 수 있는 경로를 정하지만, 경로를 고른 뒤의 전투나 점수 계산에서는
읽지 않습니다. 결속과 경로 도장은 현재 전투와 점수에 직·간접 영향이 없습니다.

## XP와 영구 보상

### 완주

| 결과 랭크 | 기본 모험 XP | 선택 경로 도장 | 참가 고양이 결속 |
|---|---:|---:|---:|
| S | 120 | +1 | 각각 +1 |
| A | 100 | +1 | 각각 +1 |
| B | 80 | +1 | 각각 +1 |
| C | 60 | +1 | 각각 +1 |
| D 분기 | 40 | +1 | 각각 +1 |

완주하면 전체 완주 횟수도 1 증가합니다. D 완주 보상 분기는 현재 도달할 수 없습니다.

경로 배율은 패배 후의 부분 XP를 포함한 모든 양수 XP에 적용됩니다.

```text
실제 지급 모험 XP = 기본 모험 XP × 경로 배율 / 100
```

정수 나눗셈의 나머지는 버립니다. 예를 들어 기본 XP 20은 새벽 정원에서 23, 130% 경로에서
26이 됩니다. 도장과 결속에는 배율을 적용하지 않습니다.

### 패배와 철수

```text
패배 XP = 패배 전에 승리한 전투 수 × 10
```

| 결과 | 기본 모험 XP | 도장 | 결속 |
|---|---:|---:|---:|
| 첫 일반전 패배 | 0 | 0 | 0 |
| 일반전 1승 후 패배 | 10 | 0 | 0 |
| 일반전 2승 후 보스전 패배 | 20 | 0 | 0 |
| 임의 철수 | 0 | 0 | 0 |

철수는 앞선 일반전을 이겼더라도 항상 0 XP입니다. 탐험별 고유 지급 ID와 최근 지급
기록을 사용해 같은 결과가 중복 적용되지 않도록 합니다.

## 모험 XP와 레벨

```text
모험 레벨 = 누적 모험 XP / 250 + 1
현재 레벨 내 XP = 누적 모험 XP % 250
레벨당 필요 XP = 250
```

| 누적 XP | 모험 레벨 |
|---:|---:|
| 0~249 | 1 |
| 250~499 | 2 |
| 500~749 | 3 |
| 750~999 | 4 |
| 이후 | 250 XP마다 계속 증가 |

현재 레벨 상한은 없습니다. 레벨과 XP 진행률은 UI에 표시되며 다음 경로를 해금합니다.

| 모험 레벨 | 새로 열리는 경로 |
|---:|---|
| 1 | 햇살 숲길·신호 지붕길·심야 기록실 |
| 2 | 새벽 정원 |
| 4 | 한낮 정거장 |
| 6 | 깊은밤 연구실 |

다음 효과는 **구현되지 않았습니다.**

- 공격력, 최대 HP, 방어, 피해 경감, 회복량 증가
- 최대 마나 증가
- 모험 레벨에 따른 능력치·적 전투력·적 HP 스케일링
- 유물·스킬·그 밖의 기능 해금

즉, 모험 레벨은 진행도이자 경로 입장 조건입니다. 파티 능력치·마나·적 수치·점수 공식을
직접 바꾸지는 않습니다. 높은 XP 배율은 일반적인 레벨 보정이 아니라 각 경로에 지정된
속성입니다.

## 경로 도장과 고양이 결속

### 경로 도장

- 경로 도장은 완주한 경로에만 1개 지급되며 경로별로 누적됩니다.
- UI에서 경로별 개수를 확인할 수 있습니다.
- 현재 보너스, 소비처, 해금 조건은 없습니다.

### 고양이 결속

- 완주하면 참가한 세 고양이에게 결속이 각각 1씩 지급됩니다.
- 고양이의 원본 활동 날짜 ID별로 누적 저장됩니다.
- 패배나 철수에는 지급되지 않습니다.
- 현재 숫자를 보여주는 UI, 결속 레벨, 능력치 보정, 스킬 해금은 없습니다.
- 원본 날짜 기록이 삭제되면 그 날짜 고양이의 결속도 삭제됩니다.

## 저장과 초기화

모험 진행도는 기존 활동 통계와 분리해 Pawprint의 SQLite 저장소에 JSON으로 저장합니다.

| 영구 저장 항목 | 내용 |
|---|---|
| 누적 모험 XP | 저장 |
| 전체 완주 횟수 | 저장 |
| 경로별 도장 | 저장 |
| 고양이별 결속 | 저장 |
| 중복 지급 방지 ID | 양수 보상이 발생한 최근 256개 저장 |

| 영구 저장하지 않는 항목 | 결과 |
|---|---|
| 진행 중 탐험과 현재 스테이지 | 앱 재실행 후 복원 안 됨 |
| 현재 HP·마나·유물 | 앱 재실행 후 복원 안 됨 |
| 전투 로그·턴 기록·탐험 시드 | 앱 재실행 후 복원 안 됨 |
| 다음 탐험의 파티·경로 초안 | 앱 재실행 후 복원 안 됨 |

세부 저장 위치는 `app_settings` 테이블의 `adventure_progress_v1` 키입니다. 초기 개발판의
UserDefaults 데이터가 있고 SQLite 데이터가 없으면 한 번 이전합니다.

- 특정 날짜 기록을 삭제하면 그 고양이의 결속과 탐험 후보가 제거됩니다. 삭제 대상이
  현재 파티에 포함되어 있으면 활성 탐험도 종료됩니다.
- 보존 기간 정리도 기간 밖 결속과 후보를 삭제하고, 대상 고양이가 포함된 활성 탐험을
  종료합니다. 누적 XP, 전체 완주 횟수, 경로 도장, 지급 방지 ID는 유지됩니다.
- 전체 데이터 삭제 시 XP, 완주 횟수, 도장, 결속, 지급 기록을 모두 초기화합니다.
- 활성 탐험 상태만 닫거나 초기화해도 이미 지급된 누적 진행도는 유지됩니다.

## 현재 구현되지 않은 확장 요소

| 요소 | 현재 상태 |
|---|---|
| 레벨별 능력치 성장 | 없음 |
| 결속 효과와 결속 표시 | 저장 카운터만 있음 |
| 도장 보상·소비·해금 | 없음 |
| 역할 3종 조합 수치 보너스 | 없음 |
| 레벨에 따른 적 난이도 증가 | 없음 |
| 영구 유물·장비·아이템 인벤토리와 강화 | 없음 |
| 진행 중 탐험 저장·복원 | 없음 |
| 방치·오프라인·백그라운드 진행 | 없음 |

## 구현 범위 주의

`AdventureEngine.resolve()`에는 초기 3라운드 자동전투용 공식이 호환 API와 테스트를
위해 남아 있습니다. 현재 프로덕션 모험 UI는 이 API를 호출하지 않습니다. 이 문서의 전투
규칙은 실제 UI가 사용하는 `AdventureEngine.performTurn()`과
`AdventureExpeditionEngine`만을 기준으로 합니다.
