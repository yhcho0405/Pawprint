# Pawprint アドベンチャーモード実装仕様

本書では、Pawprint 0.10.0 の標準 UI を維持したまま RPG を統合する開発ブランチの、
**現在のターン制アドベンチャー実装**について説明します。公開版 Pawprint 0.10.0 の
DMG には含まれていない、開発版の仕様です。企画案や今後の目標ではなく、現在実行
されるコードの数値とルールを基準としています。

> 要点：猫のレアリティグレードは HP・攻撃・防御にわずかに反映されます。
> **冒険レベルはレベル2・4・6でルートを解放しますが、戦闘能力は上昇させません。**
> 絆とルートスタンプは、引き続き戦闘効果を持たない保存カウンターです。

## 概要

| 項目 | 現在の実装 |
|---|---|
| パーティ | 過去の日付から、互いに異なる猫をちょうど3匹選択 |
| 冒険の構成 | 通常戦 → レリック → 通常戦 → レリック → ボス戦 |
| 行動 | 毎ターン猫を1匹選び、基本攻撃またはロールスキルを使用 |
| ルート | 6属性を網羅する固有設計の6ルート。うち3ルートはレベルで解放 |
| 戦闘リソース | パーティ共通 HP と共通マナ |
| 永続進行度 | 冒険 XP（レベルは XP から算出）、完走回数、ルートスタンプ、猫ごとの絆 |
| 一時報酬 | その冒険でのみ使えるレリックを最大2個 |
| 自動進行 | なし。ボタンで命令したときだけ1ターン進行 |
| レベルによる能力補正 | なし |
| レベルによる解放 | 夜明けの庭はレベル2、真昼の駅はレベル4、深夜研究所はレベル6 |
| 絆・スタンプの効果 | 累積保存のみ実装。戦闘効果や消費先はなし |
| 進行中の冒険の復元 | なし。アプリを再起動しても進行中の冒険は復元されない |

基本的な進行順は次のとおりです。

```text
図鑑から冒険を開く
  → 過去の日付の猫を3匹選ぶ
  → ルートを選ぶ
  → 通常戦1
  → レリックを1個選ぶ
  → 通常戦2
  → レリックを1個選ぶ
  → ボス戦
  → スコア・ランク・報酬を精算
```

## 3つの異なるグレード

| 名称 | 範囲 | 決定方法 | 現在の効果 |
|---|---|---|---|
| 猫のレアリティグレード | S～D | 既存の Pawpet レアリティ | HP・攻撃・防御をわずかに補正 |
| 冒険結果ランク | S～D | 完走スコアまたは失敗の有無 | ルート倍率をかける前の基本 XP を決定 |
| 冒険レベル | 1から上限なし | 累積冒険 XP | レベル2・4・6でルートを解放。能力補正なし |

猫の S グレードと冒険結果の S ランクは、名称が同じだけで別のものです。結果ランク、
XP、冒険レベル、絆、ルートスタンプによって、猫のレアリティグレードが書き換えられたり、
戦闘能力が変更されたりすることはありません。冒険レベルが変えるのはルートの利用可否だけです。

## 冒険に参加する猫

### 候補とパーティのルール

- 今日より前の日付に完成したギャラリーの猫だけが候補になります。今日の猫は除外されます。
- 基本の候補一覧と自動編成は新しい日付から順に処理されます。HUD では S→A→B→C→D の
  グレード順に表示され、同じグレード内では新しい日付から並びます。
- パーティには、日付 ID が互いに異なる猫がちょうど3匹必要です。
- ロールの重複は可能です。ガーディアン・ストライカー・サポートを必ず1匹ずつ入れる必要はありません。
- 自動編成では、可能な場合は各ロールから1匹ずつ先に選び、残りの枠を新しい候補で埋めます。
- 3つのロールをすべて編成しても、数値上の編成ボーナスはありません。ただし、すべての敵の
  予告に対応できるという構成上の利点があります。

### Pawpet の外見を RPG 特性へ変換するルール

冒険エンジンには、既存の猫が持つ4種類の特性だけが直接渡されます。その他の外見・活動特性は
直接渡されませんが、既存の Pawpet レアリティ計算に含まれる特性は、猫のグレードを通じて
HP・攻撃・防御に間接的な影響を与える場合があります。

| Pawpet 特性 | RPG 特性 |
|---|---|
| 模様（`pattern`） | ロール |
| オーラ（`aura`） | 属性 |
| 表情（`expression`） | パッシブ |
| レアリティグレード（`rarityGrade`） | 猫のグレード |

#### 模様 → ロール

| 模様コード | ロール |
|---|---|
| `plain`, `tuxedo`, `bicolor` | Guardian（ガーディアン、`guardian`） |
| `tabby`, `spotted`, `calico` | Striker（ストライカー、`striker`） |
| `colorpoint`, `star` | Support（サポート、`support`） |

#### 表情 → パッシブ

| 表情コード | パッシブ |
|---|---|
| `content`, `zen` | Steady（平常心、`steady`） |
| `sleepy`, `tired`, `dizzy` | Resilient（不屈、`resilient`） |
| `determined`, `focused`, `sparkle` | Focused（集中、`focused`） |
| `chaotic`, `mischief` | Opportunist（好機、`opportunist`） |
| `surprised`, `wide` | Alert（警戒、`alert`） |

#### 活動時刻 → オーラ → 属性

オーラは既存の Pawpet ルールで決まり、同じ時間帯コードを持つ冒険属性へ1対1で渡されます。
基準時刻は
`ゴールデンアワー → 最も忙しかった分の時刻 → 最初の活動時刻 → 正午` の順に選ばれます。

| 基準時刻 | Pawpet オーラ | 冒険属性 |
|---:|---|---|
| 00:00～04:59 | 深夜（`deepNight`） | 深夜（`deepNight`） |
| 05:00～07:59 | 明け方（`dawn`） | 夜明け（`dawn`） |
| 08:00～11:59 | 朝（`morning`） | 朝（`morning`） |
| 12:00～16:59 | 昼（`afternoon`） | 午後（`afternoon`） |
| 17:00～20:59 | 夕方（`evening`） | 夕方（`evening`） |
| 21:00～23:59 | 夜（`night`） | 夜（`night`） |

### レアリティと猫のグレード

冒険で使用するグレードは、1日の活動スコアのグレードをそのまま複製したものではなく、
既存 Pawpet の **レアリティグレード**です。

```text
レアリティ基礎スコア =
  0.70 × アイテムレアリティスコア
  + 0.30 × (Pawpet 活動努力度 × 100)

レアリティ整数値 = レアリティ基礎スコアを最も近い整数に丸める
```

Pawpet 活動努力度の範囲は `0...1`、アイテムレアリティスコアと基礎スコアの範囲は
`0...100` です。基礎スコアは小数第2位に丸めて計算し、冒険グレードはその値をさらに
最も近い整数へ丸めたレアリティから決定します。この値は既存の日別記録から再計算され、
RPG 専用の保存フィールドではありません。

| レアリティ整数値 | 猫のグレード |
|---:|---:|
| 85以上 | S |
| 70～84 | A |
| 50～69 | B |
| 30～49 | C |
| 0～29 | D |

冒険エンジンは、この最終グレードだけを受け取って使用し、レアリティや努力度を再計算しません。

## パーティ能力値

### 計算上の表記

| 記号 | 意味 |
|---|---|
| `A` | グレード補正まで適用された、行動する猫の攻撃力 |
| `G` | グレードと平常心の補正まで適用された、行動する猫の防御力 |
| `P` | 現在の敵の戦闘力 |
| `HPmax` | 3匹の猫の最大 HP の合計 |
| `w` | そのターンの決定論的な乱数補正 |

正の数の除算は整数除算のため、小数点以下を切り捨てます。

### ロール別の基本能力値

| ロール | 基本 HP | 基本攻撃 | 基本防御 | 基本回復力 | ロールスキル |
|---|---:|---:|---:|---:|---|
| Guardian（ガーディアン） | 112 | 22 | 10 | 0 | Paw Shield（前足シールド） |
| Striker（ストライカー） | 100 | 30 | 2 | 0 | Lightning Pounce（稲妻の飛びかかり） |
| Support（サポート） | 106 | 20 | 4 | 10 | Comforting Groom（やさしいグルーミング） |

ロールスキルの詳しいダメージ・防御・回復ボーナスについては、後述の戦闘式で説明します。

### 猫のグレード補正

| 猫のグレード | 内部ボーナス `B` | HP 増加 | 攻撃増加 | 防御増加 | 回復力増加 |
|---|---:|---:|---:|---:|---:|
| D | 0 | 0 | 0 | 0 | 0 |
| C | 2 | 2 | 1 | 0 | 0 |
| B | 4 | 4 | 2 | 1 | 0 |
| A | 6 | 6 | 3 | 1 | 0 |
| S | 8 | 8 | 4 | 2 | 0 |

```text
最大 HP = ロールの基本 HP + B
攻撃力 = ロールの基本攻撃 + B / 2
防御力 = ロールの基本防御 + B / 4 + (平常心なら3)
回復力 = (サポートなら10、それ以外は0) + (集中なら3)
```

パッシブを除いた、ロール・グレード別の実際の数値は次のとおりです。各セルは
`HP / 攻撃 / 防御` の順です。

| グレード | ガーディアン | ストライカー | サポート |
|---|---:|---:|---:|
| D | 112 / 22 / 10 | 100 / 30 / 2 | 106 / 20 / 4 |
| C | 114 / 23 / 10 | 102 / 31 / 2 | 108 / 21 / 4 |
| B | 116 / 24 / 11 | 104 / 32 / 3 | 110 / 22 / 5 |
| A | 118 / 25 / 11 | 106 / 33 / 3 | 112 / 23 / 5 |
| S | 120 / 26 / 12 | 108 / 34 / 4 | 114 / 24 / 6 |

レアリティグレードは回復力を上昇させません。同じロールの重複を許可した場合、
パーティ最大 HP の範囲は `300...360` です。

### パーティ共通 HP と行動する猫

- 3匹の猫の最大 HP を合計し、1つのパーティ共通 HP として使用します。
- 個別 HP や個別の戦闘不能状態はありません。
- 毎ターン、選択した猫1匹の攻撃・防御・属性・パッシブだけを行動計算に使用します。
- 行動しない残り2匹は、そのターンでは共通最大 HP にだけ寄与します。
- 表示上の防御力 `G` がそのまま被ダメージから差し引かれるわけではありません。
  基本ダメージ軽減には `G / 2` を使用します。

グレードによる防御補正は、まず `G` に適用され、その後さらに `G / 2` の整数除算を
経ます。そのため、防御 `+1` がすべての猫・すべてのターンで直ちにダメージ軽減 `+1`
として現れるわけではありません。

## ターンと行動

### 基本攻撃

```text
初期ダメージ = max(1, 2A / 3 + w), w = -2...2
```

- 共通マナを1回復します。最大マナを超えることはありません。
- ロールスキル固有のロール別ダメージボーナスは受けません。
- サポートの猫も、基本攻撃では回復しません。
- ロールが敵の予告と一致する場合、弱いカウンターボーナスと対応成功判定を得られます。

### ロールスキル

```text
初期ダメージ = A + w + ロールダメージボーナス, w = -2...2
```

| ロール | ロールダメージボーナス | 追加効果 |
|---|---:|---|
| ガーディアン | +4 | ダメージ軽減可能量に +8 |
| ストライカー | +8 | 追加効果なし |
| サポート | +0 | パーティを回復 |

ロールスキルは共通マナを1消費します。マナが0の場合、行動そのものが拒否され、
ターンと乱数状態は変化しません。

### プレイヤーダメージの計算順序

1. 基本攻撃またはロールスキルの初期ダメージを計算します。
2. 属性一致、パッシブ、敵の予告への対応、レリックのボーナスを加算します。
3. 敵が防御態勢で、ストライカーとして対応できなかった場合、敵防御
   `max(6, P / 5)` を差し引きます。
4. 実ダメージを `min(敵の現在 HP, max(1, 試行ダメージ - 敵防御))` に制限します。

有効な行動は、敵に最低1ダメージを与えます。実際の記録値は敵の残り HP を超えないため、
`ダメージ +4` の効果が撃破直前には4未満に見える場合があります。

## 属性とパッシブ

### 属性一致

行動する猫の属性と敵の属性が **完全に一致する場合のみ**、ダメージボーナスを得ます。

| 行動 | 一致時のダメージボーナス |
|---|---:|
| 基本攻撃 | `max(2, A / 10)` |
| ロールスキル | `max(3, A / 6)` |

属性同士にじゃんけん式の有利・不利はありません。一致ならボーナス、不一致なら中立です。
行動しない猫の属性も、そのターンには影響しません。

### パッシブ効果

| パッシブ | 条件 | 現在のターン制での効果 |
|---|---|---|
| 平常心 | 常時 | 防御力 `+3`、敵の反撃時に追加ダメージ軽減 `+4` |
| 不屈 | 行動開始時にパーティ HP が最大 HP の50%以下 | 追加ダメージ軽減 `+8` |
| 集中 | ロールスキル使用時 | 回復力 `+3`、さらにロールスキル回復 `+4` |
| 好機 | 行動ごとに25%の確率 | ダメージ `+7` |
| 警戒 | 各戦闘の第1ターン | ダメージ `+5` |

平常心による防御力 `+3` は `G / 2` にも反映され、その後、追加ダメージ軽減 `+4` が
別途加算されます。不屈の50%条件は、そのターンの回復より前に判定します。警戒は冒険全体の
第1ターンだけでなく、3回の戦闘それぞれの第1ターンで再び発動できます。

## 敵の予告と対応

敵の予告は公開情報です。対応するロールの猫を選べば、基本攻撃でも対応成功として記録されますが、
ロールスキルの効果のほうが大きくなります。

| 敵の予告 | 対応ロール | 未対応時の効果 | ロールスキルで対応 | 基本攻撃で対応 |
|---|---|---|---|---|
| Heavy Strike（強打） | Guardian（ガーディアン） | 高い敵攻撃 | ダメージ `+3`、ダメージ軽減 `+max(12, P / 3)` | ダメージ `+1`、左記軽減ボーナスの半分 |
| Guarded Stance（防御態勢） | Striker（ストライカー） | 敵防御 `max(6, P / 5)` | 敵防御を解除、ダメージ `+10` | 敵防御を解除、ダメージ `+5` |
| Draining Mist（吸収の霧） | Support（サポート） | 追加ダメージ `max(8, P / 7)` | 追加ダメージを解除、ダメージ `+3`、ダメージ軽減 `+max(8, P / 5)`、回復 `+8` | 追加ダメージを解除、ダメージ `+1`、左記軽減ボーナスの半分、回復なし |

敵攻撃側の独立した乱数 `w` も `-2...2` です。

| 敵の予告 | 敵攻撃の試行値 |
|---|---:|
| Heavy Strike（強打） | `3P / 4 + w` |
| Guarded Stance（防御態勢） | `2P / 5 + w` |
| Draining Mist（吸収の霧）・未対応 | `P / 2 + max(8, P / 7) + w` |
| Draining Mist（吸収の霧）・対応済み | `P / 2 + w` |

敵の攻撃は、ダメージ軽減を適用する前に最低1へ制限されます。

## 防御と被ダメージ

```text
ダメージ軽減可能量 =
  G / 2
  + ガーディアン行動ボーナス
  + 予告対応ボーナス
  + パッシブボーナス
  + レリックボーナス
```

| 項目 | ダメージ軽減ボーナス |
|---|---:|
| ガーディアンの基本攻撃 | +3 |
| ガーディアンのロールスキル | +8 |
| 平常心 | +4、防御力 `G +3` の効果とは別 |
| HP 50%以下での不屈 | +8 |
| ふかふかのケープ | +4 |
| 強打・吸収の霧への対応 | 上の対応表に記載した値 |

```text
実ダメージ軽減 = min(敵攻撃, max(0, ダメージ軽減可能量))
被ダメージ = min(回復後のパーティ HP, max(0, 敵攻撃 - 実ダメージ軽減))
```

プレイヤーの行動で敵を先に倒した場合、敵は反撃しません。この場合、被ダメージと
記録上のダメージ軽減はいずれも0になります。

## 回復

回復はロールスキルでのみ発生し、プレイヤーのダメージ処理後、敵の反撃前に適用されます。

```text
回復可能量 =
  回復力
  + サポートのロールスキルボーナス
  + 吸収の霧への対応ボーナス
  + 集中のロールスキルボーナス
  + 癒やしのハーブのボーナス

実回復量 = min(回復可能量, HPmax - 現在のパーティ HP)
```

| 項目 | 回復ボーナス |
|---|---:|
| サポートのロールスキル | +12 |
| サポートで吸収の霧に対応 | +8 |
| 集中状態でのロールスキル | +4 |
| 癒やしのハーブを持つサポートのロールスキル | +8 |

代表的な回復可能量は次のとおりです。

| 行動する猫 | 通常のロールスキル | 吸収の霧に対応 | 癒やしのハーブ込み：通常 / 対応 |
|---|---:|---:|---:|
| 集中でないガーディアン・ストライカー | 0 | 該当なし | 該当なし |
| 集中のガーディアン・ストライカー | 7 | 該当なし | 該当なし |
| 集中でないサポート | 22 | 30 | 30 / 38 |
| 集中のサポート | 29 | 37 | 37 / 45 |

集中パッシブは、サポート以外のロールスキルにも回復可能量7を与えます。ただし、実際に失った
HP がなければ回復量は0です。パッシブ名の「不屈」（`resilient`）は HP が低いときに防御を
高める効果であり、ここでいう回復力とは別の概念です。

## 乱数と再現性

- プレイヤーダメージの揺らぎは、行動ごとに `-2...2` です。
- 敵攻撃の揺らぎは、行動ごとに `-2...2` です。
- 好機は `0...3` のうち0の場合に発動するため、確率は正確に25%です。
- 敵ごとに順序の定められた予告パターンがあります。シードが開始位置を選び、その後は
  設定されたパターンを繰り返します。同じ予告を複数入れることで、隠れた乱数判定を
  増やさずに出現頻度を上げられます。
- 戦闘状態全体が同じなら、同じ猫と同じ行動を選ぶと同じ結果になります。
  シード・ステージ・ラウンドが同じ場合、プレイヤー側と敵側の2つのダメージ補正、
  好機判定、予告順が同じです。
- 拒否された行動、ウィンドウの非表示、UI の再生成、待ち時間は、乱数や戦闘状態を変化させません。
- リアルタイム制限、自動ターン、放置・オフライン進行はありません。

## ルートとステージ

すべてのルートは、通常戦2回とボス戦1回で構成されます。通常戦は各3ターン、ボス戦は
5ターンまでです。実際のルートでは敵を個別に設計しており、前半ステージをボスの戦闘力から
比率で自動生成することはありません。敵の戦闘力 `P` は `1...1000`、明示した最大 HP は
`1...2000` に制限されます。互換用イニシャライザでは HP の初期値が `2P` ですが、以下の
6ルートはすべて HP を明示しています。

### 戦闘の勝敗とステージ移行

- 敵 HP が0になると、直ちに勝利します。
- パーティ HP が0になると敗北します。
- 最後の許可ターン終了時に敵が生存していると敗北します。
- 最終ターンに敵を倒した場合は、ターン制限による敗北より勝利が優先されます。
- 通常戦で敗北すると、冒険全体が直ちに終了します。
- パーティ HP とマナは、レリック効果適用前の値を次のステージへ引き継ぎます。
  Warm Tea（温かいお茶）は HP を、Mana Bell（マナの鈴）は現在マナと最大マナを
  変更してから次の戦闘を開始します。
- ステージ間で自動的に全回復することはありません。

## マナ

| 項目 | ルール |
|---|---|
| 開始時のマナ | 2 |
| 基本最大マナ | 3 |
| 基本攻撃 | マナ `+1`、最大値まで |
| ロールスキル | マナ `-1` |
| マナ0でのロールスキル | 行動を拒否 |
| ステージ移行 | 現在マナを維持 |
| マナの鈴取得後の最大値 | 4 |

残りマナは結果状態に含まれますが、スコアや XP には反映されません。

## レリック

1回目と2回目の通常戦に勝つたび、まだ所持していないレリックが3個提示されます。
いずれか1個を選ぶと、次の戦闘が始まります。

- レリックは全部で6種類です。
- 同じレリックを重複して取得することはできません。
- ボス戦到達時にはレリックを2個所持します。
- 提示内容は冒険のシードとステージによって決まります。
- すべてのレリックは現在の冒険でのみ有効で、永続保存されません。

| レリック | 正確な効果 |
|---|---|
| Sharpened Claw（鋭い爪） | すべての基本攻撃・ロールスキルの試行ダメージ `+4` |
| Padded Cape（ふかふかのケープ） | 敵の反撃に対するダメージ軽減 `+4` |
| Mana Bell（マナの鈴） | 最大マナ `+1`、選択時に現在マナを即座に `+1` |
| Warm Tea（温かいお茶） | `max(1, HPmax / 5)` を即座に回復。最大 HP は超えない |
| Echo Charm（こだまのお守り） | 敵の予告に対応すると、行動の基本マナ変化後にマナ `+1` |
| Healing Herb（癒やしのハーブ） | サポートのロールスキルの回復可能量 `+8` |

こだまのお守りを所持してロールスキルでの対応に成功すると、消費したマナ1を取り戻せます。
基本攻撃で対応し、すでに最大マナに達している場合は、最大値を超えて回復しません。

## 完走スコアと結果ランク

敗北または撤退時のスコアは常に0です。ボスを倒した場合にのみ、次の式を使用します。

```text
HP スコア = 残りパーティ HP × 25 / パーティ最大 HP
対応スコア = 対応成功回数 × 20 / 全行動回数
効率スコア = max(0, 10 - 3 × max(0, 全行動回数 - 8))

最終スコア = min(100, 40 + HP スコア + 対応スコア + 効率スコア)
```

各除算では小数点以下を切り捨てます。

| スコア要素 | 最大点 |
|---|---:|
| 完走基本点 | 40 |
| 残り HP の割合 | 25 |
| 敵の予告への対応率 | 20 |
| ターン効率 | 10 |
| 現在の実装上の最大値 | 95 |

| 全行動回数 | 効率スコア |
|---:|---:|
| 8以下 | 10 |
| 9 | 7 |
| 10 | 4 |
| 11 | 1 |

| 結果ランク | 条件 |
|---|---:|
| S | 完走スコア90以上 |
| A | 完走スコア85～89 |
| B | 完走スコア75～84 |
| C | 完走スコア74以下 |
| D | 敗北または撤退 |

現在の3ステージで使用できる全行動回数は最大11回のため、完走スコアの実質的な範囲は
`41...95` です。現在の判定では、完走時に D ランクになることはありません。エンジンには
完走 D ランクの 40 XP 分岐が残っていますが、現在のランク判定からは到達できません。

スコア式は、最終的な残りマナやレリック数を直接参照しません。ただし、冒険中のマナ運用と
選んだレリックの効果は戦闘結果を変えるため、間接的に影響する場合があります。次の項目も、
戦闘結果を通じて間接的に影響する場合があります。

- 選択したルートに固有の敵・HP・予告パターンと固定難易度
- 猫のレアリティグレードとロール構成そのもの

冒険レベルは開始可能なルートを決めますが、ルート選択後の戦闘やスコア計算には使われません。
絆とルートスタンプは、現在の戦闘やスコアに直接・間接を問わず影響しません。

## XP と永続報酬

### 完走

| 結果ランク | 基本冒険 XP | 選択ルートのスタンプ | 参加した猫の絆 |
|---|---:|---:|---:|
| S | 120 | +1 | それぞれ +1 |
| A | 100 | +1 | それぞれ +1 |
| B | 80 | +1 | それぞれ +1 |
| C | 60 | +1 | それぞれ +1 |
| D 分岐 | 40 | +1 | それぞれ +1 |

完走すると、総完走回数も1増加します。D 完走報酬の分岐には、現在到達できません。

ルート倍率は、敗北時の一部 XP を含むすべての正の XP に適用されます。

```text
実際の冒険 XP = 基本冒険 XP × ルート倍率 / 100
```

整数除算の余りは切り捨てます。たとえば基本 XP 20は、夜明けの庭では23、130%ルートでは
26になります。スタンプと絆には倍率を適用しません。

### 敗北と撤退

```text
敗北 XP = 敗北前に勝利した戦闘数 × 10
```

| 結果 | 基本冒険 XP | スタンプ | 絆 |
|---|---:|---:|---:|
| 最初の通常戦で敗北 | 0 | 0 | 0 |
| 通常戦1勝後に敗北 | 10 | 0 | 0 |
| 通常戦2勝後、ボス戦で敗北 | 20 | 0 | 0 |
| 任意の時点で撤退 | 0 | 0 | 0 |

撤退した場合、それまでに通常戦で勝利していても XP は常に0です。冒険ごとの一意な付与 ID と
直近の付与履歴を使用し、同じ結果が重複して適用されないようにします。

## 冒険 XP とレベル

```text
冒険レベル = 累積冒険 XP / 250 + 1
現在レベル内の XP = 累積冒険 XP % 250
レベルごとの必要 XP = 250
```

| 累積 XP | 冒険レベル |
|---:|---:|
| 0～249 | 1 |
| 250～499 | 2 |
| 500～749 | 3 |
| 750～999 | 4 |
| 以降 | 250 XP ごとに増加 |

現在、レベル上限はありません。レベルと XP の進行状況は UI に表示され、次のルートを
解放します。

| 冒険レベル | 新たに利用可能になるルート |
|---:|---|
| 1 | 陽だまりの森道・シグナルの屋根道・真夜中の書庫 |
| 2 | 夜明けの庭 |
| 4 | 真昼の駅 |
| 6 | 深夜研究所 |

次の効果は **実装されていません。**

- 攻撃力、最大 HP、防御、ダメージ軽減、回復量の増加
- 最大マナの増加
- 冒険レベルによる能力値・敵戦闘力・敵 HP のスケーリング
- レリック、スキル、その他の機能の解放

つまり、冒険レベルは進行度であり、ルートの入場条件でもあります。パーティ能力値、マナ、
敵の数値、スコア式を直接変えることはありません。高い XP 倍率は一般的なレベル補正ではなく、
各ルートに設定された特性です。

## ルートスタンプと猫の絆

### ルートスタンプ

- 完走したルートにのみ1個付与され、ルートごとに累積します。
- UI でルートごとの個数を確認できます。
- 現在、ボーナス、消費先、アンロック条件はありません。

### 猫の絆

- 完走すると、参加した3匹の猫にそれぞれ1が付与されます。
- 猫の元の活動日 ID ごとに累積保存されます。
- 敗北または撤退では付与されません。
- 現在、数値を表示する UI、絆レベル、能力補正、スキル解放はありません。
- 元の日付記録を削除すると、その日付の猫の絆も削除されます。

## 保存と初期化

冒険の進行度は既存の活動統計とは分けて、Pawprint の SQLite ストレージに JSON として保存します。

| 永続保存する項目 | 内容 |
|---|---|
| 累積冒険 XP | 保存 |
| 総完走回数 | 保存 |
| ルートごとのスタンプ | 保存 |
| 猫ごとの絆 | 保存 |
| 重複付与防止 ID | 正の報酬が発生した直近256件を保存 |

| 永続保存しない項目 | 結果 |
|---|---|
| 進行中の冒険と現在ステージ | アプリ再起動後は復元されない |
| 現在 HP・マナ・レリック | アプリ再起動後は復元されない |
| 戦闘ログ・ターン履歴・冒険シード | アプリ再起動後は復元されない |
| 次回冒険のパーティ・ルート案 | アプリ再起動後は復元されない |

具体的な保存先は、`app_settings` テーブルの `adventure_progress_v1` キーです。初期開発版の
UserDefaults データが存在し、SQLite データがない場合は、一度だけ移行します。

- 特定の日付記録を削除すると、その猫の絆と冒険候補が削除されます。削除対象が現在の
  パーティに含まれる場合、進行中の冒険も終了します。
- 保存期間に基づく整理でも、期間外の絆と候補を削除し、対象の猫が含まれる進行中の冒険を
  終了します。累積 XP、総完走回数、ルートスタンプ、重複付与防止 ID は維持されます。
- すべてのデータを削除すると、XP、完走回数、スタンプ、絆、付与履歴をすべて初期化します。
- 進行中の冒険だけを終了または初期化しても、すでに付与された累積進行度は維持されます。

## 実装範囲に関する注意

`AdventureEngine.resolve()` には、初期の3ラウンド自動戦闘用の式が互換 API とテストのために
残っています。現在のアプリで使われる冒険 UI はこの API を呼び出しません。本書の戦闘ルールは、
実際の UI が使用する `AdventureEngine.performTurn()` と `AdventureExpeditionEngine` のみを
基準としています。
