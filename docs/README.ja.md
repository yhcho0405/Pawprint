## 猫たちと冒険へ

> 開発ブランチでお試しいただけるプレビュー機能です。この RPG モードは、公開版
> Pawprint 0.10.0 の DMG には含まれていません。

開発中の RPG モードでは、これまでの日々に集めた猫から3匹を選び、3連戦の
ターン制アドベンチャーへ送り出せます。6つの属性に対応する6ルートには、それぞれ
固有の敵・HP・繰り返し予告パターンがあります。冒険レベル1では3ルートを選べ、
「夜明けの庭」「真昼の駅」「深夜研究所」はレベル2・4・6で順に解放されます。
上位ルートでは、敗北時の一部 XP を含む冒険 XP が15%または30%増加します。

模様がロール、オーラが属性、表情がパッシブを決め、レアリティグレードは能力値を
少しだけ補正します。3つのロールを揃えたパーティが推奨されますが、必須では
ありません。冒険レベルはルートを解放しますが、戦闘能力を直接上げることはありません。

冒険がバックグラウンドで勝手に進むことはありません。冒険 XP、ルートスタンプ、
猫ごとの絆はこの Mac に保存されますが、進行中の冒険における HP・マナ・レリックは
メモリ上にだけ保持されます。また、冒険の報酬が活動履歴や猫のグレードを書き換える
こともありません。計算式や報酬の詳細、まだ実装されていない機能については、
[現在の実装仕様](ADVENTURE_SPEC.ja.md)をご覧ください。

## 何を見ているのか

| | |
|---|---|
| **キーボード** | 物理キーごとの打鍵数、タイピング速度、いちばん長く打ち続けた時間、ショートカット、そのうち Backspace はどれだけか |
| **ポインタ** | クリック・ダブルクリック・ドラッグ、カーソルが動いた距離、スクロールした距離、向きを変えた回数 |
| **アプリ** | どのアプリにどれだけいたか、切り替え回数、2秒で去った出入り、そしてキーとクリックがどのアプリで起きたか |
| **集中** | 途切れずに続いた区間と、それを繰り返し断ち切ったアプリ |
| **時間** | 実際に動いていた時間、画面がついていた時間、その日の最初と最後の活動 |
| **Mac の状態** | 使ったバッテリー、電源とふた、ロックと復帰、外部ディスプレイ、オーディオ出力の変更、通信量 |
| **クリップボード** | コピー・ペースト・カットの回数と、それがテキストか画像かファイルか |

すべて **数か時間** です。何をしていたかは、どこにも残りません。

## 保存しないもの

- 入力した文字と、その順番 — キーボードヒートマップは物理キーごとの回数だけを数えます。
  パスワードの `a` と検索欄の `a` を区別できず、順番も残らないので、何を打ったかは復元できません
- パスワード
- クリップボードの **中身**
- スクリーンショット、ウインドウのタイトル、文書やウェブページの内容
- 長期保存されるカーソルの軌跡

データは `~/Library/Application Support/Pawprint/` にだけあり、どこへも出ていきません。

ネットワーク通信は2種類だけで、どちらも GitHub 宛てです — 新しいバージョンの確認と、
ポップオーバーに出るお知らせの取得。どちらも設定 → アップデートの同じスイッチでまとめて切れ、
利用者や端末についての情報は一切送りません。切っておけばアプリは完全にオフラインで動きます。
利用統計の収集機能はありません。

記録中かどうかはメニューバーで常に見え、いつでも一時停止でき、特定のアプリだけ除外もできます。
全削除はボタンひとつです。

## 必要な権限

| 権限 | 理由 |
|---|---|
| **アクセシビリティ** | マウスイベントとアプリ切り替えの検出 |
| **入力監視** | キーが押されたことと、それがどの*物理キー*かの検出 — そのキーが生んだ文字は見ません |

初回起動時にセットアップウィザードが案内し、設定 → 一般からいつでも開き直せます。

macOS 14 以降、Apple Silicon と Intel Mac の両方で動きます。表示は日本語・韓国語・英語・ドイツ語に
対応していて、設定 → 一般で選ばなければシステムの言語に従います。

## アップデート

新しいバージョンが出るとアプリが自分で確認し、ポップオーバーで知らせます。一度押せば
ダウンロード・検証・インストールまで終わります。

すべてのリリースアーカイブは Ed25519 鍵で署名され、公開鍵はアプリに埋め込まれています。
署名が確認できるまでは展開すらしません — ダウンロード先が差し替えられても、別のアプリが
入ることはないように。自分で検証する方法は [SECURITY.md](../SECURITY.md) にあります。

## ソースからビルドする

**自分でビルドする必要はありません。** ここはコードに手を入れたい人向けで、使うだけなら
できあがったアプリをどうぞ:

<div align="center">
<a href="https://github.com/yhcho0405/Pawprint/releases/latest/download/Pawprint.dmg">
<img src="https://img.shields.io/badge/macOS版をダウンロード-.dmg-1a7f37?style=for-the-badge&logo=apple&logoColor=white" alt="macOS版をダウンロード" height="38">

それでもビルドするなら:

```bash
git clone https://github.com/yhcho0405/Pawprint.git
cd Pawprint
./scripts/build_app.sh release
open ./build/Pawprint.app
```

`.dmg` にまとめるなら:

```bash
./scripts/make_dmg.sh --build
```

リリース手順は [RELEASING.md](RELEASING.md) にあります。

## 困ったとき

<details>
<summary>初回起動で macOS がアプリを開いてくれません</summary>

<br>

アプリケーションフォルダの Pawprint を **右クリック → 開く** で確認してください。一度だけで済みます。

</details>

<details>
<summary>数値がすべて 0 のままです</summary>

<br>

アクセシビリティか入力監視の権限が外れている可能性が高いです。設定 → 一般で両方の現在の状態を
確認でき、同じ場所からセットアップウィザードを開き直せます。

</details>

<details>
<summary>ヒートマップに修飾キーしか出ません</summary>

<br>

Pawprint の起動後に入力監視を許可した場合、その前に作られた監視は生き返りません。
システム設定 → プライバシーとセキュリティ → 入力監視で Pawprint をオフ・オンし、
アプリを完全に終了してから起動し直してください。

</details>
